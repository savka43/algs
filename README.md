# Выражения, равные 200

Программа на JavaScript вставляет `+`, `-` или ничего между цифрами `9876543210` и выводит все варианты, равные 200.

## Запуск

Нужен Node.js:

```bash
node solution.js
```

Пример подходящего выражения:

```text
98+76-5+43-2-10=200
```

## Решение

Перебираем рекурсией три варианта для каждого из девяти промежутков: склеить цифры, поставить плюс или минус. Храним сумму завершённых чисел и текущее число со знаком. В конце выводим выражение, если его значение равно 200.

Всего проверяем `3⁹ = 19 683` варианта.
